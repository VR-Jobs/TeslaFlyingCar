# TeslaFlyingCar · 特斯拉音乐跑酷

驾驶会喷气、翻转和吸附轨道的汽车，躲避车流、收集道具，在音乐与星空中挑战更远的距离。

## 玩法

- **自由跑酷**：选择黑暗星空或浅蓝海岸，换道避开车辆，喷气越过障碍，在空中完成前翻和桶滚，挑战空中奖励航线、连续超车链与踩拍三连，安全落地可获得分数和补气；远方还会出现空间站、彗星和行星环。
- **重力翻面**：左右键选择相邻路面，空格弹射、按住 E 吸附，在地面、侧墙和天花板间接力；跟随绿色灯带避开断轨，收集补气核心，连续换面挑战本机纪录。
- **星环穿梭**：按住 E 吸附弯曲轨道，蓄力后松开弹射，飞越断轨再按 E 接轨；选择八大行星中的起点，按区段继续航行；穿过连续倾斜弯、螺旋升降和左右波浪弯，挑战分岔跳轨、空中特技连环门和动态车队，每局随机生成路线，无限向前。
- **六种奇趣挑战**：引力弹弓把握释放窗口；太空打捞拖带并交付核心；节拍造路踩拍铺路；时间回声与自己的真实录制协作；双车共振控制两车间距与角度；巨物逃生躲避采矿船拆轨。每种模式有独立教学、目标、检查点和纪录，通关后可继续无尽续航。
- **收集与爆发**：拾取补气道具继续飞行，彩虹星提供短暂无敌与双倍得分；星环中吸气可积攒最多三颗护航星，弹射时释放冲击波清理小型障碍。

## 操作

- **← / →**：普通模式换道；星环中水星至土星为简单模式，每按一次直接切换整条轨道；天王星、海王星保留连续转向的困难模式，空中按下可桶滚；重力翻面中选择换面方向。
- **空格 / ↑**：跳跃，按住持续喷气；高处再次按空格可前翻。
- **E**：星环中吸附，松开弹射；重力翻面中按住吸附，配合空格弹射换面。
- **Shift**：加速；**P**：暂停；**R**：星环与重力翻面中返回检查点。

点击「开始游戏 → 奇趣挑战」选择六种新模式；首次进入各模式会显示操作说明。普通驾驶可选择「教学引导」熟悉操作；下载后双击 `RoadsterDash.html` 即可离线游玩。
