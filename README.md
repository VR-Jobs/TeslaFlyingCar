## 启动

直接双击项目根目录的 **RoadsterDash.html**，用 Chrome 或 Edge 打开即可。脚本、字体、图片和新增模式已全部打包在一个文件中，启动无需 CMD、Node.js、本地服务器或网络。加载页与首页使用中文，首页仅保留四个入口。点击“开始游戏”先选择“黑暗星空”“浅蓝海岸”或新模式“星环穿梭”，再点“开始驾驶”；会记住上次确认的选择，“返回”不创建新游戏。

首次进入与区段切换已加入**分批构建、显卡资源预热与首次特效预热**。线上单独使用带内容哈希的游戏脚本与按需字体缓存；离线版仍是完整单文件。构建线上包用 `npm run build:online`（先生成离线 HTML），详见 [加载性能优化](docs/loading-performance.md)。

星环所有生成步骤后统一检查道具间距：车辆与红色障碍、移动/变道范围、大件道具、护航碎片和特技门之间都会留出空间。更新后请重新开局；影车会按新布局版本重新记录。详见 [道具间距](docs/star-ring-placement.md)。

**星环体验升级**：自动收起驾驶说明、压力响应喷气/吸气、踩拍蓄力—弹射—接轨、恢复补给路段、高收益分岔、本地最佳影车与自动画质均已接入。设置可独立调整彩虹边框、光晕、速度线、影车透明度和节拍校准。完成一次有效驾驶后，可在开始游戏的星环卡片下选择「挑战本地最佳影车（相同路线）」。详见 [体验升级](docs/star-ring-experience.md)。

星环也有普通场景的**金色彩虹星**了：触碰自动获得 8 秒车辆碰撞保护、双倍得分、彩虹染色喷气与气雾。首颗安排在起步中间车道，后续区段还会随机出现；顶部显示彩虹渐变状态条与倒计时。详见 [彩虹无敌星](docs/star-ring-rainbow.md)。

**星环穿梭**现在是随机无限挑战：每局使用新路线，每个区段重组星环、扭转、弯道和起伏路面，半径、方向、断轨、道具与障碍也会变化。保留补气机会、障碍通道、接轨缓冲和原有预警。区段持续向前衔接，累计里程与分数；按 P 可结束结算。详见 [随机星环规则](docs/star-ring-random.md)。

星环新增**吸气护航星、动态车队与随机航行事件**：按 E 吸入小碎片，最多积攒三颗绕车护航星；正常弹射自动释放冲击波，清理小型装置。车队缓慢前进，部分车辆在变道前提前 1.8 秒亮转向灯，安全贴车超越可补气。每隔一个区段有机会遇到补给舰、流星群、引力扰动或失联车队；保留空车道及起落缓冲。详见 [护航与随机航行](docs/star-ring-voyage.md)。

星环现已加入**分岔跳轨与空中特技连环门**：外侧金色箭头可弹射接入更短的玻璃支路，按 E 重新吸附并返航；主路和支路均有“起跳 → 桶滚／前翻 → E 接轨”的可选三连环挑战，完成后获得分数与补气。漏门可继续驾驶，提示保持在气量条旁。详见 [分岔与连环门](docs/star-ring-adventures.md)。

星环随机路线现在也有失联汽车作为障碍：采用同源 Blender 车型、黑色玻璃、尾灯和警示灯，可换道或喷气越过；碰撞会触发火花、烟雾和灰阶镜头，按 R 重试。每排保留可通行车道，断轨前后保持净空。详见 [星环汽车障碍](docs/star-ring-traffic.md)。

星环现已接入与另外两个场景同源的三层喷气、车底吸气流、空中前翻和桶滚；弯轨未按 E 会先失稳预警，补救失败后飞离轨道并进入灰阶死亡镜头。按 R 返回检查点并恢复必要气量，提示保持在气量条附近。详见 [星环飞行与吸附表现](docs/star-ring-flight.md)。

星环首次进入还有简短的三步实操教学：**吸附 → 松开弹射 → 重新接轨**。提示只显示在顶部小区域，练习不计时、不扣分；可以跳过，完成后会记住。暂停菜单中可随时选择“重学新手教学”。

断轨前的边灯会变成琥珀色并向前流动；**两侧青白灯段与上行双音表示推荐弹射窗口**。在窗口内松 E 或空格起跳，短喷后越过断口，再按住 E 接轨。灯光随车速、气量调整，低速或缺气时先保留警告；能量条旁仅有小字，不再增加挡车横幅。

星环曲面现已修复进出口重叠和背面穿透：环路出口横向错开，正面、底面和侧面共用实体碰撞几何；从轨道背面冲上去会被挡住，只能从可驾驶正面接轨。镜头也会避开实体路面，三处断轨与既有教学继续保留。

星环现采用**半透明玻璃轨道与三条纵向光边**，透过板面可看到下方冰尘环带，侧前方为土星风格的条纹行星。玻璃只是外观变化，原有实体碰撞和断轨预警继续生效；全部效果仍内嵌在可双击离线运行的 HTML 中。

轨道已移除横向分格、横梁、托架和弹射阶梯灯，保留左、中、右三条纵向光边，以及道路外侧的磁悬浮翼片、方向灯与导航柱。吸附段、星环、连续弯道与冲刺段分别使用克制的浅紫、青绿、冰蓝和暖金边光。装饰保留车道净空，三处真实断口没有横梁或灯带跨接。

星环轨道现接入真正的**选择性 HDR Bloom 后期泛光**：边框、导向灯和弹射光条带柔和光晕，汽车与行星保留遮挡并排除发光，玻璃板面仍然通透。后期缓冲随画质限制分辨率，全部代码保留在双击运行的 HTML 中。

“设置 → 作品来源与许可”支持查看作者/第三方许可、导出和导入进度。单文件版的存档与此前本地服务器版分开；可以从原版开发台导出，再在单文件版导入。移动 HTML、更换浏览器或清理浏览器数据前，建议先导出存档。

## 教学引导与原有增强功能

本轮增加落地前输入缓存、低高度翻转反馈、预计落点、按冲击速度变化的缓冲与烟雾，以及随机车流的连续路线预测。星空具有四段视觉旅程；驾驶车辆采用同源 Blender LOD；设置中加入镜头强度、音量、按键和旅程涂装。详细参数、修改入口与验证范围见 [驾驶手感与星空旅程](docs/driving-polish.md)。

首页通过 **开始游戏** 启动正常自由驾驶，通过 **教学引导** 选择训练。旧挑战模式、排行榜、商店与其他功能的恢复代码和存档仍保留，本版隐藏其首页入口。

训练共 14 关：变道跳跃、飞行补气、桶滚落地，以及空气补给、满气补充、护盾、冲击波、超加速、星光无敌、火箭能量、开局冲刺、自动复活、碰撞后复活和双倍金币。道具实训调用实际游戏效果，提供免费试用，不消耗背包。

训练成功后主按钮显示 **下一关**，点击或按空格继续；失败时显示 **重试**。第三关会衔接道具训练，顺序完成全部训练后显示 **完成训练 · 自由驾驶**。旧版前三课的完成记录和奖励继续保留。训练记录不计入竞技排行榜或普通驾驶最佳成绩；开局冲刺演示不会刷取里程金币，双倍金币课程单独演示基础金币翻倍。

详细规则、各建议对应的代码位置与实际验证范围见 [设计改进说明](docs/design-improvements.md)。规则检查：`npm run check:features`；训练目标、存档和奖励检查：`npm run check:academy`。开发台的“运行增强回归”会用实际 60 Hz 模拟跑通全部 14 关及后续跳转，并检查未通过时仍可重试。

## 中文精简首页与暗黑星空

首页使用纯白与特斯拉正红色（#e31937）界面，保留原版圆形车台、钢架和可旋转座驾，移除背景集装箱。纯黑天空搭配更明显的白色星点，地面、车台与环境灯光调暗，突出车身。主界面显示约 1 秒后，座驾即开始喷气升空、前翻或桶滚，再落回车台；从驾驶返回首页也会重新安排。鼠标移动时，镜头会以小幅平移、倾斜产生立体照片般的景深视差；不需要按住拖动，车身朝向保持固定，喷气表演继续播放。鼠标离开画面或窗口失去焦点后平滑回正。没有夕阳、星球或星云。当前首页标题为“特斯拉音乐跑酷”，仅有 **开始游戏、教学引导、操作指南、设置** 四个按钮；不再显示账户、金币、成就、商店、场景切换或全局语言按钮。详见 [中文加载与四入口封面](docs/chinese-minimal-cover.md)。

车身现有白色轮廓高光，背景和地面保持暗色；喷气更明显并配有音效。首次点击任意首页入口会启用音频，音效、音乐与静音可在“设置”中调整。首页动作逐帧检查实际车身顶点的离地间隙，避免翻转穿过车台；气流在车台表面淡出。详细修改与验证见 [轮廓光、音效与防穿模说明](docs/rim-light-jet-fix.md)。

首页表演现已增加蓄力、平滑升空、空中翻转、喷气减速下降、接地缓冲及小幅回弹；落地烟雾向四周散开，音效随各阶段变化。修改入口与最新回归说明见 [自然升空与缓冲落地](docs/natural-showroom-animation.md)。

首页轻微镜头视差在 `src/scenery/showroom-parallax.js`，最大横移 0.26、纵移 0.11 个场景单位、滚转约 0.29 度，采用平滑跟随，并遵循系统的减少动态效果设置。

首页布局和样式在 `src/local/home.js`、`src/local/minimal-home-styles.js`；训练面板样式仍在 `src/local/home-styles.js`；3D 背景在 `src/scenery/space-menu.js`。课程清单、双语目标和奖励在 `src/features/lessons.js`，实际道具教学在 `src/features/item-training.js`。所有内容仍打包进根目录的 `RoadsterDash.html`。

## Blender 首页汽车

首页与驾驶车辆使用同源 Blender 外观，2026-10-26 按用户提供的白色原型车照片调整车顶曲线、黑色玻璃、白色 C 柱与后肩、轮毂银色面和尾部结构。宽尾板绕前缘铰链开合，伸缩支撑随动；黑色玻璃同步三档模型与全部场景。可编辑源文件、GLB 与检查图在 `models/roadster-2026/current`，原模型备份在 `models/roadster-2026/revisions/20261026-blackglass/baseline`。详细修改、精度范围与编辑后打包方法见 [Blender 汽车说明](docs/blender-roadster.md)。没有原厂 CAD 或完整测量尺寸，本版为照片指导的外观近似，不宣称工程级一比一。

## 黑暗星空游戏场景

游戏内默认启用黑暗星空，保留原来的道路、车流、碰撞、跳跃和计分规则。周围为黑色宇宙、分层星点、淡银河尘带、带陨石坑与明暗分界的远处天体，以及跑道两侧缓慢自转的小行星。道路和车身使用中性冷白光，夜间车灯继续工作。远处星空跟随相机位置，近处小行星产生驾驶视差。

在 **设置 → 游戏场景** 可选择黑暗星空、浅蓝海岸或原版风景，选择保存在本机；首页仍只有四个按钮。所有新增视觉内容均由本地代码生成，仍可双击单个 HTML 离线游玩。参数在 `src/config/space.js`，场景接入在 `src/scenery/space-game.js`；星点、小行星与着色器分别在 `space-stars.js`、`space-details.js`、`space-shaders.js`。详细实现与验证见 [黑暗星空场景](docs/space-game.md)。空间净空和区块连续性检查：`npm run check:space`。

## 浅蓝海岸场景

浅蓝海岸保留为可选场景：清透淡蓝海面、自然涌浪、浅水焦散、碎浪沫、金黄色干湿沙滩、椰子树、海草、灌木、地被小花、贝壳、漂流木、潮间礁石和远处海岛。椰树包含弯曲树干、不规则树皮叶痕、独立羽状小叶、老叶、椰果与轻微风摆，幼树和高树形成疏密变化，使用实例化绘制重复植被。

在设置中选择“浅蓝海岸”即可恢复。独立观景的恢复代码仍在项目中，其首页入口继续隐藏。

颜色、太阳方向、曝光和椰树数量在 `src/config/coast.js`；海水与天空着色器在 `src/scenery/coast-shaders.js`；椰树几何与材质在 `src/scenery/palms.js`；场景、沙滩与切换入口在 `src/scenery/coast.js`；海岸装饰和植被在 `src/scenery/coast-details.js`；独立观景镜头在 `src/scenery/coast-viewer.js`。海岸内容通过本地桥接层安装，没有改动原版核心物理或碰撞规则。

海面位移与光照共用带解析导数的五组色散波浪，避免起伏与法线不匹配。浅水透明混合真实沙底与水下礁石，深水逐渐变为不透明，再叠加光学水深、动态焦散和天空反射；属于实时近似，并非光线追踪或完整的屏幕空间折射。所有新增资源由代码生成，仍然包含在单个 HTML 中，不需要联网下载。`npm run check:coast` 检查装饰在区块循环时的位置连续性与道路净空。

例如在 `src/config/gameplay.js` 修改 `PHYSICS.jumpHeight` 后刷新游戏，即可改变跳跃高度。开发台可以先即时试验，再把需要保留的数值写入源码。纯游戏窗口没有开发台侧栏。
