# TeslaFlyingCar · 特斯拉音乐跑酷

驾驶会喷气、翻转和吸附轨道的汽车，躲避车流、收集道具，在音乐与星空中挑战更远的距离。

[在线试玩](https://vr-jobs.github.io/TeslaFlyingCar/) · [Codespaces 在线工作区](https://codespaces.new/VR-Jobs/TeslaFlyingCar?quickstart=1) · [下载游戏](https://github.com/VR-Jobs/TeslaFlyingCar/archive/refs/heads/main.zip)

## 玩法

- **自由跑酷**：选择黑暗星空或浅蓝海岸，换道避开车辆，喷气越过障碍，在空中完成前翻和桶滚，挑战空中奖励航线、连续超车链与踩拍三连，安全落地可获得分数和补气；远方还会出现空间站、彗星和行星环。
- **星环穿梭**：按住 E 吸附弯曲轨道，蓄力后松开弹射，飞越断轨再按 E 接轨；穿过连续倾斜弯、螺旋升降和左右波浪弯，挑战分岔跳轨、空中特技连环门和动态车队，每局随机生成路线，无限向前。
- **收集与爆发**：拾取补气道具继续飞行，彩虹星提供短暂无敌与双倍得分；星环中吸气可积攒最多三颗护航星，弹射时释放冲击波清理小型障碍。

## 操作

- **← / →**：普通模式换道；星环中轻点微调、长按持续转向，空中按下可桶滚。
- **空格 / ↑**：跳跃，按住持续喷气；高处再次按空格可前翻。
- **E**：星环中吸附，松开弹射，飞跃后再按住接轨。
- **Shift**：加速；**P**：暂停；**R**：星环中返回检查点。

首次游玩可选择「教学引导」熟悉操作；下载后双击 `RoadsterDash.html` 即可离线游玩。
