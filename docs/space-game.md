# 黑暗星空游戏场景

本次新增的是实际驾驶环境，首页原有黑色展台独立保留。首次使用默认进入星空；之后沿用“设置 → 游戏场景”的本机选择。原有浅蓝海岸和原版风景仍可选，首页入口保持四个。

## 画面

- 8,690 个确定性星点，分为均匀背景星、银河带密集星和少量高亮星。星色略有冷暖变化，避免统一白色圆点；低画质减少绘制数量。
- 黑色背景上叠加克制的银河、暗尘带和细碎亮区。没有白昼天空、海岸植被或夕阳；远景跟随相机平移，避免恒星像近处物体一样飞掠。
- 远处无大气天体使用程序化陨石坑、月海色差、细碎凹凸及明暗分界；弱暗面保留轮廓。
- 两侧小行星有不规则轮廓、岩石颜色和凹凸、缓慢自转与近景视差，48 个实例共用几何和材质，低画质使用 24 个。
- 中性冷白主光、低强度环境光和离线生成的反射环境让白色车身可读。道路沿用原纹理、标线、宽度和动态几何，远处逐渐融入黑暗，夜间交通车灯保留。

这些是面向实时游戏的程序化视觉近似，并非真实恒星目录、天体物理或真空模拟；原有驾驶重力、烟雾、喷气与道路结构保持原规则。

## 修改入口

`src/config/space.js` 控制种子、星点数量、光照、曝光、天体位置与小行星区块。`src/scenery/space-game.js` 负责环境选择、光照覆盖和逐帧接入；另外三个 `space-*.js` 文件分别负责星点、实例化岩石和着色器。`src/local/developer-bridge.js` 安装场景。

新环境通过现有环境/视觉更新入口接入，没有重写核心物理或碰撞。切换时恢复原环境，海岸继续调用原有模块。所有几何、噪声与反射在本地生成，没有新增外部图片、模型或网络请求。修改后运行 `npm run build:html` 重新生成双击版。

## 验证

`node tools/check-space.mjs` 检查实际生成的星点和实例矩阵：种子可复现、属性有限、远星距离与画质缩放；小行星包围球始终位于道路两侧，跨 100、5,000、5,200、50,000 米区块时保留对象的世界坐标连续。`node tools/verify.mjs` 对照原始核心函数与玩法参数。

浏览器验证包含真实开局与驾驶、场景切换、首页四入口、控制台着色器错误，以及最终单文件版无外部资源依赖。对应截图和报告保存在 `evidence/space-*20261025*`。
