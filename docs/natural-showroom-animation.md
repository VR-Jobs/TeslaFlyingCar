# 自然升空、翻转与缓冲落地（2026-10-25）

启动方式不变：直接双击根目录 RoadsterDash.html，无需 CMD、服务器或联网。首次点击右上角“开启声音”可启用喷气声，原声音/静音设置继续有效。

本版将首页表演调整为：轻微预压蓄力 → 平滑升空 → 高处翻转 → 恢复正姿并用喷气减速下降 → 接地缓冲和小幅回弹。前翻约 5.2 秒，桶滚约 4.8 秒，悬浮约 4.6 秒；每次表演后仍留有休息间隔。起落高度及旋转使用平滑曲线，喷嘴切换交叉淡入淡出。悬浮时镜头只轻微拉远，翻转时保留足够空间。

落地缓冲只作用于车身和姿态，车轮保持在车台上。实际模型检查得到约 3.3 cm 的下压、约 7 mm 的小幅回弹，随后衰减回正。原有实际顶点离地检查继续执行；空中安全间隙平滑过渡到静止间隙，避免接地时突然跳变。

接地时触发一次 72 团柔和烟雾，从车身周围沿地面向四周扩散，并在约 2.2 秒内消失。烟雾使用代码生成的点精灵和噪声着色器，无外部贴图；进入车库或离开首页时清理。

音效随动作变化：低频蓄力、起飞增强、翻转时气流和音调变化、降落前空气制动、接地时轻微低频落地声与扩散气流声。复用原版 Web Audio 声音总线，遵循静音，支持首次点击解锁。没有新增网络音频文件。

代码入口：
- src/scenery/showroom-motion.js：动作时长、分段曲线、喷嘴切换、悬挂和镜头。
- src/scenery/showroom-landing.js：落地烟雾、扩散、消散与清理。
- src/scenery/showroom-audio.js：推力/气流包络、翻转音调与接地音效。
- src/scenery/showroom-clearance.js：实际部件顶点离地保护。
