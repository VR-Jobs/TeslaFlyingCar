# 星环道具间距

问题原因：基础道具、车队、红色障碍簇、额外补气、彩虹星和护航碎片在不同步骤生成，原先缺少最终统一检查。只比较车辆初始位置也无法覆盖后续前进与变道。

placement.js 在全部玩法生成完成后执行一次。按各道具外壳尺寸及旋转范围计算平面占位，车辆计入完整 maxTravel 与变道横向扫过范围，沿道路额外留出 4 米可读空间。护航碎片也计入与大件道具和车辆的距离；特技门框附近预留空位。

优先保留 required 补气、两颗彩虹星、飞跃环及节奏晶核。必要时取消会扫过必要道具的变道、限制车辆前进或移除冲突障碍。普通道具优先保持纵向位置并移到开放车道，其次在安全实心轨道上前后寻找位置；确实没有位置的可选道具才省略。护航碎片可横向错开，仍处于 E 吸收范围内。

不在驾驶中临时移动或隐藏道具，不增加逐帧布局扫描。布局仍由种子确定。EXPERIENCE_VERSION 更新为 experience-2-clearance，旧版影车布局不再混用；新一局会重新记录，原有成绩与其他存档继续保留。

npm run check:placement 覆盖 768 个随机区段、车辆运动快照、红色障碍、必要补气、取消冲突变道、护航碎片、门框和跨区段预览。另执行随机路线全程、车流、分岔、彩虹、节奏体验及加载回归。实机工具为“验证：道具间距”。修改前副本位于 revisions/20261027-placement。
