# 星环七项体验升级

## 游玩入口

仍双击 RoadsterDash.html 启动，封面仍只有开始游戏、教学引导、操作指南、设置。开始游戏后选星环；已有有效影车时，卡片下可勾选“挑战本地最佳影车（相同路线）”。暂停或结算也可挑战影车。新路线挑战保留随机种子变化。

## 七项变化

1. 驾驶超过 8 秒自动切为精简 HUD，底部细条保留气量、彩虹剩余量和护航星。教学保留说明。顶部只有一条当前关键动作提示；吸附危险优先于断轨，其次特技与路线选择。
2. 喷流与吸气强度随剩余气压变化，四个尾喷口有不同脉动相位。松加速时带短促泄压声，原三层气体与固定气雾池继续复用。
3. 按住 E 踩拍蓄力，随后在节拍上弹射与接轨可完成节奏三连。普通踩拍 +30，三连额外 +120，彩虹时按统一倍数结算。成功后约 12 拍增加短旋律层；漏拍不扣分、不改变碰撞。按实际音频时钟判定，可在设置校准 ±150 ms。无声音时仍可正常驾驶。
4. 每段包含观察、连续挑战与补气缓冲区，恢复区清理可能驶入的车流并设置气罐。低气量前进可额外恢复最多 10 点，停住无法刷气。保留断轨安全空间、必要补给和开放车道；节奏航段有按基础速度/128 BPM 排列的晶核及两侧节拍灯。
5. 蓝色主路保持稳定补给，金色支路保留空中特技并提高返回奖励（进入 +120、返回 +320，特技另算）。影车仅视觉显示、没有碰撞；接近玩家时自动淡出。记录与随机种子绑定，选择影车模式会复用相同路线。最多 4800 采样，长局逐步降低采样频率；浏览器本地保存，测试工具不写入用户影车。
6. 设置可单独调整彩虹边框、驾驶光晕、速度线、影车透明度；可关闭影车、自动画质和精简 HUD。彩虹末段改为缓慢褪色提示，保留减少动态效果偏好和既有镜头设置。
7. 星环根据持续帧耗时调节内部目标分辨率、远景细节和粒子数量。使用迟滞与冷却时间，避免来回跳档；遵守原有手动画质上限，暂停和初次预热不参与测量。帧耗时、P95 与最长帧可在开发诊断查看。

## 代码与验证

director.js、rhythm.js、ghost.js、adaptive-quality.js、experience-view.js 分别管理编排、节奏、本地记录、画质与视觉。没有改写 src/game.js 的原始函数。

npm run check:experience 覆盖恢复区、关键提示优先级、节奏时窗与去重、音乐层、自动画质迟滞和手动上限、影车保存/插值/容量/错种子隐藏及几何复用。另运行随机全程、分岔、车流、航行事件、彩虹、喷气、异步加载、离线及在线包检查。实机验证入口为“验证：七项体验升级”。
