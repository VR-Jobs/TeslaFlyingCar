# 星环汽车障碍

正式随机无限挑战中约八成障碍改为失联汽车，其余保留原来的红色装置。汽车静止贴合真实轨面，覆盖弯道、星环与倒挂路段；四种车漆按种子变化。采用现有 Blender 汽车的轻量版本，保留黑色玻璃、车轮、灯组和尾翼，车灯参与原有选择性光晕。警示灯闪动；系统减少动态效果偏好启用时改为常亮。

每排仍最多封住两条车道。按真实车宽校验避让间距，断轨前后、中心补气及接轨缓冲继续保留。正常玩法可以提前换道，也可以及时起跳并短喷越车。汽车是静态障碍，不会突然切入可行车道。

碰撞使用玩家旋转后的车身包围范围在障碍的局部轨面坐标中做连续扫掠，考虑车宽、车长、车高与桶滚／前翻姿态；不再沿用矮装置的车道距离检测。碰撞触发火花、烟雾、原撞击音效及飞离轨道的灰阶镜头；失败界面显示撞车原因，按 R 回检查点。撞到的汽车不会凭空消失。暂时无敌与新手教学的既有保护保留。

渲染将同源 Blender 模型合并成七类共享网格，重复利用几何与材质。各窗口只绘制附近车辆，随区段退役释放网格和光晕缓存；撞击火花使用固定 32 粒子池。原模型数据复用已有单文件资源，无新下载或远程依赖。

维护入口：
- src/star-ring/random-course.js：车辆比例、车漆与安全排布。
- traffic.js：共享网格车辆、黑色玻璃、灯光和火花。
- traffic-rules.js：车体尺度与连续扫掠碰撞。
- simulation.js：汽车碰撞、失败原因及重试。
- route-window.js、view.js：窗口归属、更新和释放。
- tools/check-star-ring-traffic.mjs：128 个随机种子、实车尺寸、越车、倒挂、高速和资源检查。
