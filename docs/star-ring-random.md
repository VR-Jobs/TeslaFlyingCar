# 随机星环无限挑战

正式玩法中，每次开始和重新挑战都会取得新种子；同一局内，每个区段用种子与区段编号派生不同路线。路线包含星环、完整扭转、左右连续弯和起伏路面，随机决定模块顺序、星环半径、扭转方向、弯道朝向、弯曲半径、起伏幅度和连接直道长度。不是沿固定赛道每三段交换车道。

断轨在足够长的平直走廊中随机放置，手动缺口长度约 20～27 游戏单位；第一处使用较短的 18～20 单位缺口与自动弹射，其他断口需要玩家操作。前方保留至少 88 米障碍缓冲，后方保留至少 104 米的接轨区域；断轨的边灯、时机音效沿用真实几何与当前速度判断。

可选道具形成不同位置、间距和车道的收集串。星环与扭转段布置中心补气，断轨前后也有中心补给，保证存在不依赖运气的能源路线。障碍可单独出现或封住两条车道，每排至少留一条路；相邻障碍排至少相隔 84 米，中心补给附近和准备飞跃时保持中心通道。该间距按当前最高 48 的速度上限考虑；仍需玩家正确吸附、变道、弹射和接轨。

前一个区段末端和后一个区段开头都以水平直道连接，画面和碰撞共用相邻真实路线。区段长度可以不同；总里程累加已完成区段的实际长度，镜头和车身按实际位移一起重置局部坐标。

渲染仅保留当前窗口与一个待用窗口。下一区段分批预载，碰撞面、玻璃与底部结构每批约 6 ms 后让出执行时间；材质、旧网格与对应的 Bloom 蒙版缓存随窗口退役清理。临时曲面采样缓存只在构建时存在。停止或重新开始可以取消预载；浏览器调度与垃圾回收会使实际批次耗时浮动，这不是固定帧率保证。

入口仍是“开始游戏 → 星环穿梭”。首页四个按钮、新手教学、大尺寸道具和暂停结算保持。全部代码内嵌在 RoadsterDash.html，继续支持双击离线游玩。

维护入口：
- src/star-ring/random-course.js：随机种子、模块组合、障碍与补给规则。
- random-pilot.js：仅供测试的真实操作控制器，不会替玩家开车。
- route-window.js、build-scheduler.js：窗口预载、取消与释放。
- course.js、track-surface.js：实体曲面与连续碰撞。
- tools/check-star-ring-random.mjs：128 组布局规则及多组种子的真实驾驶。
- tools/check-star-ring-random-streaming.mjs：退役网格和光晕缓存释放。
- tools/check-star-ring-random-async.mjs：分批预载与取消后重建。

带 starRingQA=1 参数才会显示验证按钮；额外 ringSeed=11 可以复现某条测试路线。正常游戏每次开始仍会随机。旧版本备份在 revisions/20261026-random-baseline。
