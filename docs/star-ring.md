# 星环穿梭

2026-10-26 起正式入口默认为 [无限挑战](star-ring-endless.md)，下述有限赛道路线和通关流程作为原始机制与回归基线保留。

点击首页“开始游戏”，在三张卡片中选择“星环穿梭”，再点“开始驾驶”。首页仍保留原来的四个按钮，独立 HTML 中已内嵌新代码、汽车网格、音乐程序和预览图，不需要额外下载。

## 简短新手教学

首次进入自动在起航平台原地练习三步：① 按住 E 半秒吸附；② 松开 E 弹射；③ 空中重新按住 E，保持到接轨。触屏使用同一个“吸附”按钮。每步按实际操作推进，不会按倒计时自行通过；第三步放慢物理时间，给新手留出阅读与操作的时间。没有重新按住吸附就落地，会免费重试。

提示直接复用顶部的小标题、单行说明和细进度条，练习期间收起普通计时／得分行与额外提示，不在汽车上方新增横幅。练习不计入赛道时间、分数、接轨统计或恢复次数；完成后从起点开始正式穿梭。右上角“跳过”可立即开始，暂停菜单的“重学新手教学”可重新练习。完成或跳过的版本记录保存在原本地存档中，重新挑战不反复弹出；原有通关、纪录和涂装保持。

## 玩法

### 玻璃轨道与土星环带

星环轨道采用半透明玻璃，只保留左、中、右三条连续纵向光边。已移除横向格线、错缝接头、横梁、横跨道路的托架和弹射阶梯光条；碰撞面的厚度与三车道操作保持原规则。中央光边使用窄带几何改善远处细线的覆盖，玻璃板面保持淡冷色透明和掠射反光。

吸附扭转段使用浅紫色，第一星环偏青绿，连续弯道偏冰蓝，极光星环与终点偏暖金；变色主要落在纵向光边和外侧细灯。

保留外侧金属侧梁、锁扣、磁悬浮翼片、方向箭头和路段导航柱。金属件全部在车道宽度外，不在可驾驶面上制造没有碰撞的假障碍。三处断轨按真实断口截断侧梁与中央光带，预警只作用于两侧纵向边灯。装饰按距离分批显示，系统减少动态效果时导向灯保持静止。

背景加入土星风格的条纹气态行星、带径向层次和行星阴影的冰尘环带。环带在平直跑道下方约 20 米，透过玻璃可看到细颗粒与星光；少量近景冰尘只分布在轨道下方或外侧。行星和星空使用游戏美术比例，新增内容均由代码生成并内嵌单文件。低画质减少近景粒子，普通自由驾驶与海岸场景不受影响。

这是透明混合与菲涅尔效果的轻量玻璃表现，不使用屏幕空间折射。玻璃分块共享原有 23,580 个实体三角面，透明材质不写入深度，避免把后方星空挡成黑块；车身仍正常遮挡远处亮边。轨道实体厚度、吸附、背面阻挡、翻转碰撞和三处断轨保持原规则。

### 轨道后期泛光

星环模式使用独立的 HDR 后期流程：先绘制正常场景，再单独绘制纵向光边、方向灯、导航柱、断轨灯和道具的发光来源，经过亮部提取与五级高斯模糊后叠加，最后做 ACES 色调映射和屏幕颜色转换。细亮芯保持清楚，外侧扩散柔和光晕，低频的大范围雾光被压低。

车身、金属骨架和行星在发光来源图中只参与遮挡，不会因为白色而触发泛光；普通星点和非发光透明板面不进入泛光图。行星、环带和玻璃的程序颜色转换到线性空间，避免接入后期后把黑色宇宙变成灰白色。警告灯与弹射窗口仍跟随原来的时机和减少动态效果设置，不额外闪屏。

后期随星环模式按需创建。低／中／高档的 HDR 主图分别限制在约 72／130／210 万像素，模糊链进一步缩小；退出模式后缩小缓冲区并恢复原渲染状态。普通星空和海岸模式继续使用原流程，独立 HTML 已内嵌全部代码。

### 曲面正反面与实体碰撞修复

两个星环的入口、出口沿横向错开 20 米，绕环仍完成一整周倒挂，入口和出口不再占用同一空间。可驾驶正面的边框较亮，底面与侧面边光较弱；实体轨道厚度为 0.45 米。

渲染和碰撞共用 track-surface.js 生成的 Float32 三角面，包括正面、底面、侧壁和断口端面。飞行时对接地点和车体探针做逐帧扫掠检测，底面碰撞会挡回车辆，不能从背面吸附穿到正面。贴轨时也检查是否扫入另一段轨道。接轨搜索细化原来的 1.5 米采样，只有从可驾驶正面接近时才允许落地；位于断口空白处时不会向远处边缘的虚拟平面吸附。

车身在贴轨状态跟随轨面朝向，减小弯道上朝向滞后造成的穿入。镜头加入实体轨道遮挡检测，车辆被挡在轨道下方时，镜头也留在下方，不穿过路面。故意缺失的三处断轨继续保留。

### 断轨灯光与弹射时机

接近断轨时，两侧纵向边灯由冷白过渡为琥珀色并朝断口流动，通常提前约 2.6 秒开始提醒（范围按车速限制在 55～140 米）。短提示音分三段，越近音调越高；推荐弹射区由两侧青白色纵向灯段表示，进入窗口时只响一组上行双音。第一个自动弹射台单独标为“自动弹射”。不再绘制跨越道路的横灯或阶梯光栅。

按住 E 时，窗口按“松 E 弹射”估算；没有按 E 时，按“空格起跳”估算。推荐动作是在窗口内离轨，短喷约 0.35 秒，接近断口另一侧后再按 E 吸附。窗口根据当前车速、断口长度、起跳方式和剩余气量更新；加速飞行还预留额外耗气。低速、气量不足、或未来加入的弯曲断口只保留警告，不显示推荐区。它是当前操作条件下的建议，并不保证任意喷气时长、变道或加减速后仍能接轨。

正常驾驶不再弹出原来的断轨文字条，能量条旁仅有“断轨将至”“松 E · 短喷”等 11 像素短提示，车身区域没有新增遮挡。静音／关闭音效不影响灯光；系统减少动态效果时边灯保持静态。暂停、重开及检查点恢复会取消未播放的第二声，返回检查点后可重新提醒。

车辆自动向前。路线长约 2,360.9 米，依次经过启航平台、贴壁倒挂、第一星环、弹射航道、连续弯道、深空飞跃、极光星环、螺旋归航与终点冲刺。轨道是真实的世界坐标曲面，离轨后车辆保留切线速度，并受世界重力影响；并非只旋转画面的平面道路。

| 操作 | 效果 |
| --- | --- |
| 按住 E | 强吸附，靠近轨面时拉回并接轨 |
| 松开 E | 沿当前轨面法线弹射离轨 |
| 空格／上键／W | 跳跃；持续按住会消耗气量喷气修正 |
| 左右键／A、D | 三车道移动；离轨稍后再次按可做一次完整桶滚 |
| Shift | 加速并消耗气量 |
| 下键／S | 降低目标速度 |
| R | 返回最近检查点，计入一次恢复和 4 秒罚时 |
| P／Esc | 暂停；暂停菜单可开关助航吸附、重开或回首页 |
| M | 静音 |

新模式目前使用上表固定按键。原普通驾驶的六项按键重映射继续有效。触屏提供吸附、喷气、加速和左右按钮。镜头加速时的视野变化遵循设置中的镜头强度和系统减少动态效果；轨道方向变化仍保留，否则无法看清壁面和倒挂道路。

气量在平直朝上的路段补充，贴壁倒挂、喷气和加速会消耗；绿色补气罐恢复 26，蓝色晶核加分，金色空中环提供更高分。连续收集、完整桶滚与成功接轨可以叠连击。开启音乐后，距真实音乐拍点 100 毫秒内的起跳或接轨额外 +30；路边灯仅轻微呼吸，星空保持稳定。

### 道具模型与收集反馈

绿色补气罐包含透明罐体、金属端盖、护杆、阀门和表盘；蓝色积分晶核包含切面晶体、发光内核和分段轨道环；金色飞跃环使用镂空双环与三段外框，中间可看到汽车穿过。模型使用颜色和形状双重区分，并保留原来道具的位置、获取范围、气量和计分规则。

道具轻微悬浮、旋转，附近带少量轨道粒子。补气时绿色气流向汽车收拢，晶核收集后散出蓝色碎光，穿越金环时扩散金色细环与光点，三类反馈使用不同音色。粒子共用一批绘制，收集效果复用八个槽位，结束后回收，不新增大字横幅。重开或检查点恢复同步已收集集合，避免旧道具再次爆出粒子；减少动态效果时关闭待机粒子轨道并缩减收集粒子数量。

全程两个完整纵向星环、两段扭转和三处真正缺失的轨道。首个断口有自动弹射帮助学习，后两处需要自行起跳。断口边缘为橙色，空中显示预计落点和圆周光幕。车辆补光随轨面方向变化，倒挂时仍可看到车身；落地压缩、烟雾与声音根据下降冲击变化。使用同源 Blender 驾驶外观，尾翼底座、支撑与车身保持关联。

掉落只返回最近检查点，不结束整局。擦碰扣气、降速并罚时 2 秒，保留继续机会。通关显示耗时、得分、收集数、桶滚、接轨、踩拍、恢复和擦碰统计；按表现授予“星环旅人／平稳穿梭／星环大师”称号。金币为 25 + 收集环数 × 2，首次完成额外 50；同一局只结算一次。解锁“星环银蓝”涂装，在设置的旅程涂装中选择。

## 验证

`npm run check:star-ring` 检查曲面坐标架、接缝连续、真实断口、输入事件保留、飞行、检查点和全程可完成性。脚本策略能完成全部路段，最新接轨、恢复次数与耗时见 evidence/star-ring-physics-checks.json；这不是无失误通关证明。浏览器中的独立检查覆盖实际渲染、完整结算、单次奖励和涂装解锁，报告在 evidence/star-ring-browser-checks.json。?starRingQA=1 仅供开发，正常打开不显示测试按钮，测试结算后会恢复原存档。

`npm run check:html` 验证经典内嵌脚本与离线资源；`npm run check` 验证原始核心指纹和本地存档。浏览器自动化以同一完整 HTML 的本地 HTTP 字节运行，file:// 导航受测试浏览器策略限制；没有声称自动执行了磁盘双击。

`npm run check:star-ring-tutorial` 验证 16 项教学行为：真实按住与短按、弹射、未操作的落地不能过关、再次吸附、无练习计分、跳过与旧存档兼容。浏览器检查与三个步骤的实际截图保存在 evidence/star-ring-tutorial-*。普通打开 HTML 不显示开发按钮。

`npm run check:star-ring-gaps` 验证 12 项预警行为，包含两处手动断口、27/28/32/42 m/s、两种离轨方式、窗口两端和中点共 48 次实际物理飞行；另检查低气量、加速耗气、提示音去重、暂停取消和恢复重置。浏览器检查与实际画面在 evidence/star-ring-gap-*。测试使用短喷 0.35 秒、距对岸 3 米开始接轨的固定操作策略，未宣称覆盖所有玩家动作。

`npm run check:star-ring-surfaces` 检查 14 组实体轨道行为，包括三条车道共 1,707 段车体扫掠、591 条镜头视线、正反面法线、精确断口端面、从下方向上吸附的阻挡、侧壁碰撞、高速下降落地与低空桶滚碰撞。报告在 evidence/star-ring-surface-checks.json，浏览器实景与运行验证在 evidence/star-ring-surface-*。车辆碰撞使用接地点和车体探针近似，尚未使用完整汽车三角网格作刚体碰撞体。

`npm run check:star-ring-glass` 核对玻璃与碰撞面的逐顶点一致性、透明深度设置、碰撞数据不被修改、结构件净空、断口不被跨接、装饰预算与远处批次隐藏，以及行星距离、环带高度、冰尘净空与低画质粒子数量。实际渲染、弹射提示、底面阻挡与通关回归在 evidence/star-ring-glass-*。细化轨道的多角度截图在 evidence/star-ring-track-*，模式卡片使用此次场景的真实截图。
