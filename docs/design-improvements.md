# 设计建议落地：驾驶学院与挑战版

这是在本地恢复项目上新增的一层可选玩法，原版核心类与默认参数仍保留。主菜单点击 **驾驶学院 · 挑战** 进入模式选择，或直接点击“开始”启动当前选择。首次使用默认进入驾驶学院，毕业后转为自由驾驶。

## 逐项实现

| 建议 | 当前实现 | 入口 / 源码 |
| --- | --- | --- |
| 前三局逐步教学 | 三堂可复习课程：两次变道与跳跃落地；持续飞行 1.2 秒并达到 3 米后落地；完整桶滚与完美落地。分别行驶 150 / 200 / 220 米完成，首次奖励 10 / 15 / 20 金币；失败不会解锁课程，重玩不重复发奖 | 学院卡片、课程 1/2/3；`src/features/rules.js`、`index.js` |
| 明确特技与落地质量 | 完整旋转、姿态误差、落地速度共同判定完美落地；显示旋转完成度和落地对齐提示；完整桶滚、前空翻、飞越车辆与实际加分反馈 | `src/features/index.js`、`rules.js` |
| 解释失误与进步 | 区分超时断连、没有有效技巧、碰撞；低气量警告与气量条闪烁；结束后显示最佳动作、最长连击和一个具体的下一局建议 | `src/features/messages.js`、`ui.js` |
| 更公平的危险节奏 | 保留原版预留通路算法，在此基础上增加低气量疏车、周期性恢复路段、新生成车辆的相对反应距离保护，以及同车道危险预告 | `src/features/fair-traffic.js` |
| 精准驾驶 | 无碰撞完成 800 米；较疏车流与最高 30 m/s 目标速度，完成后自动结算 | 精准驾驶卡片 |
| 特技表演 | 60 秒内完成 6 次完整特技和 3 次完美落地；达标或超时自动结算 | 特技表演卡片 |
| 极限逃脱 | 在逐步提速和加密的车流中坚持 45 秒，达标自动结算 | 极限逃脱卡片 |
| 固定每日赛道 | 每日 1,200 米课程；UTC 日期和版本号生成种子。车辆与补给按世界距离布置，不随玩家加速或耗气变化。不能使用起步道具或复活 | 每日赛道卡片；`courseRows()`、`dailySeed()` |
| 可比的排行榜 | 纯技巧、道具、学院练习、旧版分别显示；按模式、规则版本分类；每日榜限定当天完成课程的成绩。旧存档不强行归为纯技巧记录 | 模式窗口下方“本地分类榜”、原菜单排行榜与结算排行榜入口 |

## 单独体验与对比

- **原版模式**：关闭新增的教学、反馈、车流调整，保留原来的玩法数值与处理方法。
- **自由驾驶**：三个开关可分别开启或关闭，用于单独对比操作提示、特技反馈、公平车流。切换回原版再返回自由驾驶时会保留这些开关的选择。
- **学院与评分挑战**：统一锁定反馈和车流规则，避免不同配置混排。学院成绩作为练习数据，不进入纯技巧榜。
- 保持中文默认与 English / 中文即时切换。新增模式窗口、HUD 提示和赛后复盘都有中英文。

## 文件结构

`rules.js` 保存可测试的课程、日种子、固定车流、落地等级和榜单分类规则；`fair-traffic.js` 负责车流适配；`index.js` 在实际游戏实例上安装可关闭的运行时增强；`ui.js` 与 `public/assets/driving.css` 负责模式窗口和反馈；`messages.js` 提供双语文案。

存档仍使用原有本地存档键。初始化时为旧存档补充学院进度与模式偏好，不清空金币、成绩或车漆。新记录增加 mode、ruleset、seed、道具使用、复活次数与教学指标；旧记录保留为 legacy。

## 验证与边界

运行 `npm run check` 检查保留核心与原始参数，再运行 `npm run check:features` 检查新增规则。开发台有“运行玩法回归”和“运行增强回归”两个独立按钮。

- 原有 7 组工程检查通过，15 个关键类 / 函数的语法结构指纹和 16 组原版参数仍匹配。
- 新增 7 组规则检查通过，包含 100 个种子的固定布局与相邻地面通路、落地边界、教学目标与奖励幂等性、每日限制和榜单隔离。
- 浏览器内新增 8 项增强检查通过：三堂实际物理模拟课程、加速与不加速的每日车辆位置一致、三种挑战结算条件、原版模式退出增强。
- 三种挑战的“结算条件”测试临时关闭碰撞，只验证模式生命周期和目标结算；教学与每日布局检查保留碰撞。它们不代表所有随机车流或所有设备都已经完成长时间人工平衡试玩。
- 原来的 8 项操作模拟回归仍通过，保留变道、跳跃、飞行、翻转、加速与固定步长重复性。

证据见 `evidence/design-feature-checks.json` 和 `evidence/design-browser-checks.json`。每日布局是本项目新增规则，原版服务器、全球排行榜和付款依旧没有接入。当前榜单仅在本地浏览器内比较。

另外已在成品构建用实际键盘输入完成第一堂课，确认提示、自动结算、首次奖励、下一课进度和练习记录衔接正常。
