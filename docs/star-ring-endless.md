# 星环无限挑战与实体道具

点击“开始游戏 → 星环穿梭 → 开始驾驶”。首次仍有吸附、弹射、重新接轨三步教学，首页保留四个按钮。

正式驾驶默认进入无限挑战：每个约 3 公里、长度可变的星环区段结束后连续接上下一段，保留总里程、分数、连击、时间与收集统计，不出现自动通关弹窗。每段变换道具／障碍的车道分布，提供补气和区段奖励；巡航速度从 28 提升到最多 36，推进速度从 42 提升到最多 48，增加难度有上限。本轮已改为逐段生成不同的模块顺序和几何参数，详见 [随机路线](star-ring-random.md)。

按 P 暂停，可以继续，或选择“结束并结算”。最远距离、最高分和最长驾驶时间单独保存在本机；原有有限赛道的成绩不覆盖。返回主菜单也会结算当前有效驾驶，结算有幂等保护。脱轨后先播放失控飞行与灰阶镜头，再按 R 返回本区段最近检查点并补充必要气量；不会清空累计分数和已完成区段。弯轨仍需按住 E。详见 [飞行与吸附表现](star-ring-flight.md)。

气罐改成更大的金属／陶瓷压力容器，加入阀门、保护带、压力表与绿色状态灯。蓝色积分物改成六边形金属能量核心，带凹入透镜、螺栓和散热结构。飞跃环有分段外框、厚度、连接点与窄光槽，内径约 4.2 游戏单位。气罐和核心整体缩放为 1.8，较原版更醒目；车道收集范围同步调整。装饰和模型使用本地几何及材质，无新增网络资源。

无限衔接使用固定的局部轨道窗口（前 80 米、长度可变的主区段、后 600 米）及同一份实体三角面碰撞。过界时将车身、镜头和落地特效一起重置局部坐标，世界运动连续；道具和障碍状态集合按区段清理，道具数量按区段限制、8 槽收集特效复用。网格、材质与后期不随距离持续增加。GPU 的首次可见资源会按需上传，持续增长与初次上传应分别测量。

修改入口：
- `src/star-ring/endless.js`：衔接、速度上限、统计与纪录。
- `course.js`、`track-surface.js`、`track-detail.js`：周期轨面、预览窗口和实体碰撞。
- `pickups.js`：实体道具、尺寸、材质与复用特效。
- `index.js`、`ui.js`：实际启动、暂停结算和小型 HUD。
- `tools/check-star-ring-endless.mjs`：60 Hz 十二区段路线、接轨、重生和固定资源检查。

旧版本保存在 `revisions/20261026-endless-baseline`。游玩只需双击 `RoadsterDash.html`，无需命令行、Blender、服务器或网络。
