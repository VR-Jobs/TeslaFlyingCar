# 星环彩虹无敌星

沿用普通场景 STARMAN 的 8 秒持续时间、2 倍得分、1.6 倍加速和 80 分撞开奖励参数。触碰金色五角星立即生效，无需新按键；车身缓慢变色，彩虹染色喷气及气雾跟随真实车体、翻转和曲面，玻璃保持黑色。气量条旁显示倒计时，不增加封面按钮。

每个随机区段有两颗主路星星：第一颗约在 132–158 米中间车道，第二颗在后续路段随机选择。优先使用空位，必要时替换普通可选晶核/补气，保留所有 required 补气点；星星远离断轨、分岔起落区与车辆。下一段预览也可能提前看见星星，进入下一段后按新索引收集。

生效时车辆碰撞会将障碍车向外撞开，小型装置也受保护；每辆车只奖励一次。车道得分、道具、特技、护航星、节拍和区段奖励均采用同一倍数。自动维持贴轨吸附并补充气量；安全普通直道加速（最高 48 m/s），断轨、特技门、弯轨与捷径保留原有安全速度。跳跃、换轨和实体路面碰撞仍正常判定，不穿过轨道底面。

结束后有 0.7 秒车辆碰撞缓冲，避免正好与车辆重合时立即失败。车漆、发光和音色复原，尾迹自然消散。按 R 或死亡清除效果，保留已收集记录，不能反复刷同一颗；未结束的效果可跨区段保留，旧的撞飞位置与尾迹在重定位时清除。

实现位于 rainbow-rules.js、rainbow-geometry.js、rainbow-view.js。喷气使用既有三层冷气模型，只改变发光颜色；尾部喷气为四喷口立体气流与软气雾两个批次，32 个历史采样；撞飞最多记录 6 辆，沿用原车网格。道具颗粒沿用 8 槽收集特效池，新增网格继续进入异步构建和 GPU 预热。在线使用哈希脚本和按需字体缓存，离线版仍双击 RoadsterDash.html 启动。

`npm run check:star-ring-rainbow` 覆盖 256 个随机区段、实际收集、时效和缓冲、双倍得分、撞车/小障碍保护、弯轨吸附、速度安全区、检查点与跨区段、车漆复原、黑玻璃、固定尾迹池和车辆撞飞。另运行随机完整驾驶、分岔、碰撞、加载一致性、离线及在线包检查。修改前副本为 revisions/20261027-rainbow-star。

屏幕表现与普通黑暗星空、浅蓝海岸场景共用 game.css 的彩虹边缘遮罩、旋转渐变、彩虹分数与收集闪光；中心 52% 透明，效果层不接收鼠标。剩余 2 秒使用原有结束提示，暂停冻结颜色，结束、死亡和退出清理；减少动态效果偏好下停止旋转与闪烁。能量面板增加六色剩余时间条，仍不增加遮挡汽车的大字。验证入口为「验证：彩虹屏幕」。

尾部效果升级为四个真实尾喷口的立体冷气喷流。exhaust-wake.js 用 8 边截面、32 个历史采样生成一个气流网格，另一个固定 192 粒子的软气雾批次；不再绘制六条长平面彩带。沿用原版嵌入噪声纹理，表面软边、双尺度湍流侵蚀及 0.32 秒消散；按历史车辆变换跟随翻转和弯轨，并用历史路面裁切。普通加速呈冷白气流，彩虹状态对气体轻度染色。保留屏幕彩虹边框。

`npm run check:exhaust-wake` 检查四喷口锚点、旋转后有限值、192 粒子上限、缓冲复用、消散、低动态模式、历史路面裁切、死亡与区段重定位；实机入口「验证：喷气尾流」同时检查原版气流层、彩虹边框和光晕预算。
