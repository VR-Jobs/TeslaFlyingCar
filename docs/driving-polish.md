# 驾驶手感、车流与星空旅程

仍然双击根目录 RoadsterDash.html 即可离线运行。首页保持开始游戏、教学引导、操作指南、设置四个按钮。

“开始游戏”现在先打开双场景选择页：黑暗星空 / 浅蓝海岸，点击“开始驾驶”才确认场景并开局。默认选中上次确认的场景，取消不改动场景或创建游戏。海岸在确认时才按需初始化。菜单空格/回车同样经过选择页；重试沿用本局场景。设置中的场景入口仍保留。实现见 src/local/scene-picker.js、scene-picker-styles.js。

两张场景卡片使用当前游戏渲染器的实际截图，同为 350 米驾驶视角。截图时隐藏 HUD 并排除底部开发工具条；原始 PNG 和取景记录在 evidence/scene-preview-*-source.png、scene-preview-capture.json。tools/pack-scene-previews.py 仅缩放并压缩为 WebP，生成 public/previews 与 src/assets/scene-preview-data.js；图片以内嵌 data URL 加入单文件，不依赖外部图片文件或网络，也不为显示预览而提前创建海岸场景。

## 操作与反馈

- 下落时预计离地接触时间不超过 160 ms，提前点按跳跃可缓存 180 ms；松开不会丢掉点按，但会取消后续持续飞行。失焦、暂停、重置和撞车清除缓存。
- 下一次起跳在前一次落地的碰撞检查与连击结算之后执行，避免覆盖落地奖励。正常跳跃和原有空中翻转保留。
- 下落高度不足、预计时间不足或能量不足时，不强行开始新桶滚。方向输入仍可变道，屏幕右上边缘短暂显示小提示并播放短音，不用大型横幅遮挡车身。
- 道路上的淡椭圆显示当前轨迹的预计落点。估计以当前速度、重力及已选车道为依据，按住飞行时降低不确定标记的亮度；后续操作会改变落点。这是视觉辅助，不参与碰撞。
- 落点圆圈边缘向上延伸 1.65 个游戏单位高的环形渐变光幕，中间留空，不含中心光柱、中心光晕或封顶面。光幕底边与圆圈椭圆边缘对齐，冷白偏蓝的底部较亮，向顶部渐隐。与圆圈共享位置、可见性和提示颜色，车辆可正常遮挡光幕，落地后一起消失。
- 落地冲击以接地前垂直速度为共同依据，驱动原有音效、缩减后的径向烟雾和有界车身悬挂。车轮保持地面接触高度，车身最大下压约 0.063 个游戏单位。
- 碰撞结算提供一条具体原因；撞车动画期间可点“立即重开”或按 R，跳过等待并在本局结算完成后重新开始。

入口：src/features/handling.js、handling-rules.js。160/180 ms 是首版手感参数，可在后续实际游玩中继续校准。

## 车流公平性

自由驾驶等随机车流在生成新车时，预测未来 4.2 秒的地面可达路径。使用当前速度、车辆相对速度、车宽车长、反应余量、当前变道剩余时间、空中动作余量和有/无能量的变道耗时，沿横向移动过程采样，不把相邻车道视为瞬移可达。变道车预留其横向运动区间。

新生成的阻塞车辆向远处推迟，最多重试四次；仍无可达路径时省略该新车。已经存在的车不移动。该预测采用保守采样，不保证玩家任意后续输入、速度突变或故意冲向障碍都能避开。

教学与每日固定布局不按个人操作改位置；在创建时以无能量、100 m/s 的条件检查完整地面走廊，保留同种子可复现性。新版规则标识 driving-v2，将历史计分记录分开。

## 星空与资源

从近地轨道渐变至月球、小行星带、行星背光，约 4,700 米进入最后一段。行星海洋、陆地、云和大气边缘均为程序材质，并非真实地球测绘贴图。天体远离跑道，星空不随节拍闪烁；微弱节拍只作用于道路边缘细灯。

海岸在首次选择时创建，首次进入星空不创建海水、沙滩与椰林。选过海岸后缓存资源，避免反复重建。中文单文件只内嵌中文与拉丁字体；日、韩文字如出现使用系统回退字体，完整原字体源文件和许可仍保留。

## 同源车辆 LOD

原 Blender 源文件 models/roadster-2026/current/roadster-exterior.blend 保持原字节哈希。

| 用途 | 导出几何三角面 | 文件 |
| --- | ---: | --- |
| 主界面 | 150,968 | current |
| 驾驶 | 33,491 | lod/driving |
| 低画质或远镜头 | 19,385 | lod/distant |

每级另有 48 个运行时尾翼支撑三角面。保留相同部件槽、轮心、灯光材质和尾翼连接；普通交通车辆继续使用原有低面数车型。原模型仍是照片指导的外观近似，不是原厂 CAD。新增驾驶外壳保留碰撞与刚体撞车动作，未重做原版网格变形损伤。

编辑同源资产后，以已有 Blender 执行 tools/build-roadster-lods.py，再运行 node tools/pack-roadster.mjs、node tools/standalone.mjs。GLB、原生 .blend、几何检查和固定相机图均在各 LOD 文件夹；法线使用 snorm16、适合的索引用 uint16 内嵌，位置仍保持 Float32。运行时缓存几何避免重复解码。

## 教学、设置和成长

推荐前三节基础课，道具专项折叠为选学。三课完成后可直接开始自由驾驶；所有 14 课仍可选择，成功主按钮继续为下一关。

设置中可独立调整音乐、音效、镜头晃动、鼠标视差、速度模糊，后三项可调到零；保留原画质设置并遵循系统减少动态效果。六项驾驶按键可重映射，冲突时交换；操作指南、底部键位和空格教学文案同步。菜单开始、暂停/继续等界面快捷键仍沿用 Space/Enter/P/Esc。

旅程记录以单局距离、平稳落地和完整特技解锁四种涂装，保存在原本地存档中，仅在设置中展示，不新增首页入口。目前未新增歌曲资源、歌曲关卡或拍点准确率计分。

## 验证入口

- node tools/verify.mjs：原始核心指纹、配置、语法、本地存档与结算。
- node tools/check-handling.mjs：反应锁、完整横向移动、低能量、三/五车道、23/55/100 m/s，96 组新车批次与旅程边界连续性。
- node tools/check-roadster-lods.mjs：三级实际运行时顶点、法线、三角形与各 101 个尾翼/车身姿态；原源文件哈希保护。
- node tools/check-html.mjs：单文件脚本和离线资源约束。
- 仅开发测试时打开带 ?iterationQA=1 的 HTML，可运行真实游戏操作和全部 14 课回归；普通打开不显示测试工具。测试报告写入 evidence，截图为实际浏览器画面。
